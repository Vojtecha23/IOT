# Úloha 07 – Ovládání bzučáku a servomotoru pomocí PWM

## Popis úlohy
V této úloze jsem vytvořil jednoduchý grafický dashboard pomocí knihovny Tkinter, který umožňuje ovládat bzučák a servomotor připojené k Raspberry Pi.

Pomocí dvou posuvníků mohu měnit intenzitu výstupu pro bzučák a polohu servomotoru. Pro ovládání obou zařízení využívám softwarové PWM prostřednictvím knihovny gpiozero.

## Použité součástky
- Raspberry Pi
- Bzučák vhodný pro PWM ovládání
- Servomotor
- Propojovací vodiče
- Externí napájení servomotoru podle jeho požadavků

## Zapojení
**Bzučák:**
- Kladný vstup (+) → GPIO18
- Záporný vstup (−) → GND

**Servomotor:**
- Signálový vodič → GPIO13
- Napájecí vodič → externí zdroj odpovídající parametrům serva
- Zemnicí vodič → GND Raspberry Pi a externího zdroje (společná zem)

Bzučák musí být vhodný pro přímé ovládání z GPIO. Pokud odebírá větší proud, je nutné použít tranzistorový spínač.

## Princip fungování
Po spuštění programu se otevře grafické okno se dvěma posuvníky.

**První posuvník – bzučák:**
- Rozsah 0–100 %
- Nastavuje střídu PWM signálu
- Při hodnotě 0 % je PWM výstup vypnutý

**Druhý posuvník – servomotor:**
- Rozsah 0–100 %
- Hodnota 0 % odpovídá jednomu krajnímu natočení
- Hodnota 50 % odpovídá středové poloze
- Hodnota 100 % odpovídá druhému krajnímu natočení

Program převádí hodnotu druhého posuvníku na rozsah −1 až +1, který používá knihovna gpiozero pro řízení servomotoru.

## Použité knihovny
- **tkinter** – vytvoření grafického dashboardu
- **gpiozero** – ovládání PWM výstupu a servomotoru

## Závěr
V této úloze jsem si vyzkoušel ovládání dvou zařízení pomocí grafického prostředí a PWM. Naučil jsem se převádět hodnoty posuvníků na hodnoty potřebné pro ovládání bzučáku a servomotoru. Výhodou je jednoduché a přehledné ovládání obou zařízení z jednoho okna.
